# digital-baby-book
A digital baby book application for storing milestones, photos, videos, and memories.
The Digital Baby Book is an application designed to help families save and organize important childhood memories. Users will be able to create profiles for multiple chi;dren and add milestones, photos, videos, dates, and notes.
## Planned Features
- User sign up and login
- Profiles for multiple children
- Milestone entries
- Photo and video uploads
- Custom themes
- Timeline or playback of memories
- Sharing access with family members
